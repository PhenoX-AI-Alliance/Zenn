## 1. 背景：なぜ「防衛的」な最適化が必要だったのか

Pythonのボトルネックを解消する際、手動でCython化（`.pyx` の記述、`setup.py` のCコンパイラ連携、メモリのゼロコピー化のための `memoryview` や `numpy.C_CONTIGUOUS` の保証）を行う作業は、エンジニアにとって膨大な「デバッグ時間」と「精神的疲弊」を伴います。

- 突然やってくる `SIGSEGV`（セグメンテーション違反）によるPythonインタプリタの突然死。
- `setup.py` とCコンパイラ（gcc/clang）のバージョン不整合が引き起こす無限のビルドエラー。
- 「ゼロコピー」という言葉を信じて実装した結果、メモリレイアウトの不整合（非連続アレイ）によって裏で暗黙のコピーが発生し、逆にレイテンシが悪化する絶望。

私たちは、単なるベンチマーク上の「爆速」を追い求めるのをやめました。真のROIは**「エンジニアの稼働時間（精神負荷）の削減」**にあります。

## 2. 泥臭い失敗ログから生まれたシステムアーキテクチャ

### 2.1 自動C拡張化におけるセグメンテーション違反（SIGSEGV）の回避

動的AST解析で型をCのプリミティブに落とし込む際、境界チェックを無効化した結果、致命的なクラッシュが発生しました。

```text
[FATAL] 2026-08-12 22:14:02,104 - cython_runtime - Process crashed with SIGSEGV (Segmentation fault)
Context: Unchecked C-pointer indexing in dynamic ast-inferred loop.
```

これを防ぐため、コード生成器に安全性のフォールバック（例外送出モード）をデフォルトで有効化する安全弁を実装しました。

```python
    def compile_and_load(self, func: Callable, source_code: str) -> Callable:
        """
        関数オブジェクトとソースコードからCythonモジュールを動的ビルドする。
        コンパイルエラーや環境依存の問題が発生した場合は、元のPython関数を返す（フォールバック）。
        """
        func_name = func.__name__
        
        try:
            self._run_cython_build(pyx_path, module_name)
            return self._load_module(so_path, func_name)

        except Exception as e:
            logger.warning(f"Cythonization failed for {func_name}: {e}. Falling back to pure Python execution.")
            return func
```

### 2.2 「ゼロコピー」の罠と、デッドロックの回避

NumPyなどのバッファを直接Cレベルで操作しようとした際、メモリレイアウトの不整合によるエラーに直面しました。

```text
[ERROR] 2026-08-12 23:40:15,892 - memory_profiler - ZeroCopy buffer acquisition failed: Buffer is read-only or not C-contiguous.
```

そこで、バックエンドに厳格なメモリレイアウト検証フェーズ（`ZeroCopyValidator`）を義務付けました。

```python
class ZeroCopyValidator:
    @staticmethod
    def validate_and_wrap(array: np.ndarray) -> np.ndarray:
        if not array.flags['C_CONTIGUOUS']:
            logger.warning(
                f"Memory layout warning: Array of shape {array.shape} is NOT C-contiguous. "
                "Zero-copy Cython access will trigger an implicit memory copy."
            )
            return np.ascontiguousarray(array)
        
        logger.info(f"Memory layout OK: Array of shape {array.shape} is C-contiguous. Zero-copy ready.")
        return array
```
