# Claude Codeを2時間おきに回してVS Code拡張mdエディタを育てる：Loop Engineering実践

近年の生成AIの進化スピードは凄まじく、人間がプロンプトを投げてその都度コードを受け取る「単発の壁打ちスタイル」から、AIが自律的にタスクをループ処理してシステムを成長させる**「Loop Engineering（ループ-エンジニアリング）」**の時代へとシフトしています。

本記事では、筆者が実際に導入している「Claude Codeを2時間おきにcron等で自動実行し、VS Code拡張機能のMarkdownエディタを継続的に育成-機能追加していく」という実験的な開発手法の全貌と、この自律開発アプローチが地球環境インフラやレジリエンス向上にどう貢献しうるのかを論じます。

---

## 1. Loop Engineeringとは何か？

Loop Engineeringとは、AIコーディングアシスタントに対し「現在のリポジトリの状態を確認する」「TODOリストから次のタスクを1つ選ぶ」「実装-テスト-コミットまでを自動で行う」という一連のループ（サイクル）を定期的に回し続ける開発パラダイムです。

人間は「何を達成すべきか」の方向性（Charter）とガードレール（制約事項）を定義するだけで、細かなコードの記述、リファクタリング、バグ修正はすべて自律エージェントがバックグラウンドで遂行します。

---

## 2. 実践：2時間おきのClaude Code駆動開発

筆者は、自作のVS Code用Markdown拡張機能の機能拡張を、以下の仕組みで回しています。

1. **トリガー**: cronにより2時間ごとに専用のシェルスクリプトが起動。
2. **コンテキスト読込**: リポジトリ内の `TODO.md` および直近の Git Commit 履歴をClaude Codeにインプット。
3. **タスク選択と実行**: 「プレビュー機能の高速化」「数式レンダリング（KaTeX）のバグ修正」「エクスポート機能の追加」などから1件を選び、実装。
4. **検証とコミット**: 自動テストを走らせ、パスすれば自動コミット＆プッシュ。

これにより、寝ている間や他の作業に集中している間にも、エディタ機能が勝手にリッチになっていくという驚異的な開発スピードを実現しています。

---

## 3. 自律開発が地球環境インフラやレジリエンス向上に果たす役割

こうした「AIによる自律ループ開発」は、単なるソフトウェア開発の効率化に留まりません。地球規模の課題解決やレジリエンス（回復力）向上に直結するポテンシャルを秘めています。

- **省電力コードの最適化**: ループ内でCPU使用率やメモリ消費量をプロファイリングし、環境負荷の低い（電力消費を抑えた）アルゴリズムへと自動リファクタリングを繰り返す自律エージェントの構築。
- **インフラ監視-災害復旧システムの自動レジリエンス向上**: 気象データやセンサー情報を入力として受け取り、24時間365日止まらないインフラ制御コードを自己修復-自己拡張し続けるループの確立。

人間が疲弊することなく、AIが持続的にシステムをメンテナンスし続ける仕組みこそが、これからの地球環境インフラを支える基盤となります。

---

## 4. まとめ

Loop Engineeringは、ソフトウェア開発の概念を根底から変えるアプローチです。AIを単なる道具として使うのではなく、「自律的な協働パートナー」として組み込むことで、個人開発者であっても大規模チーム並みの速度と品質を達成できるようになります。
