深夜の突然のアラート、果てしないスタックトレース、そしてローカル環境での泥臭い原因究明。シニア・ミドルエンジニアであれば誰もが経験するこの「深夜のオンコール地獄」を打破するため、私たちは自律型デバッグパイプライン**「Midnight-Patch-Daemon (m-patch)」**を構築しました。

本記事では、例外発生からスタックトレース解析、ローカルLLMによる修正パッチ生成、サンドボックスでの自動テスト、そしてGitHub PR発行までを人間が介入せず3分で完結させるアーキテクチャと、そこに秘められた技術的リアリティを公開します。

---

## 1. なぜクラウドLLMではなく、ローカルLLMなのか？

実務のコアなインフラにAIを組み込もうとすると、以下の壁に直面します。

1. **機密情報の外部流出リスク:** 本番環境のスタックトレースには、機密データが含まれる可能性がある。
2. **レイテンシとAPIコスト:** 例外発生のたびに外部APIを叩くことによる従量課金の高騰。
3. **ブラックボックス化されたアップデート:** クラウドLLMの仕様変更によるプロンプトの崩壊。

だからこそ私たちは、社内ネットワーク内で完結するローカルLLM（`qwen2.5-coder:7b-instruct`）を選定しました。VRAM 24GBクラスの環境で量子化を施して動作させ、モデルバージョンを完全に固定して制御下に置いています。

---

## 2. パイプラインの全貌：AIを「暴走させない」3重のガードレール

LLMを用いた自動化で最も恐ろしいのは、「AIが勝手に存在しない関数をインポートして本番をさらに破壊する」という二次災害です。本システムは、堅牢なフェイルセーフによって暴走を完全に押さえ込みます。

```mermaid
flowchart TD
    A[Production Python App] -->|HTTP Webhook| B[FastAPI Backend Receiver]
    B -->|Celery + Redis| C[Patch Generation Worker]
    
    subgraph Worker Pipeline
    C1[1. 文脈スライシング & AST周辺コード抽出] --> C2[2. Ollama API / Local LLM でDiff生成]
    C2 --> C3[3. AST静的バリデーション]
    C3 -->|Syntax OK| C4[4. Docker Sandbox / git apply & pytest]
    C3 -.->|Syntax NG / Retry| C2
    end
    
    C --> Worker Pipeline
    C4 -->|Tests Passed| D[GitHub API: 自動PR発行]
```

### 3つの防壁（フェイルセーフ）

1. **文脈スライシング（Context Slicing & Token Optimization）**
   例外が発生した該当フレームの関数ブロックとその上下30行のみを抽出し、プロンプトのトークン量を常に1,500トークン以内に抑えることで、ハルシネーションの確率を最小化しています。
2. **AST静的検証 ＆ サーキットブレーカー**
   Pythonの `ast` モジュールを用いて抽象構文木レベルでの静的バリデーションを挟み、構文エラーや未定義シンボルのインポートを弾きます。
3. **サンドボックス自動テスト**
   隔離された一時的なDockerコンテナ環境で `git apply --check` と `pytest` が全パスした時のみ、GitHubへプルリクエストを発行します。

---

## 3. 直面した生々しい失敗と対策

### 🛑 失敗①：LLMが「挨拶」して `git apply` が即死した
* **事象:** 「お疲れ様です！スタックトレースを分析しました…」といった無駄な愛想笑いが混ざり、自動パース処理が崩壊。
* **対策:** システムプロンプトに `Output ONLY a valid unified diff` という極めて強い否定条件を明記し、対話バイアスを完全封鎖しました。

### 🛑 失敗②：ハルシネーションによる「存在しない便利関数」の錬成
* **事象:** LLMが勝手に存在しないユーティリティ関数を生成し、テスト実行時に `ImportError` で即死。
* **対策:** AST静的検証を導入し、標準ライブラリおよびローカルに実在するシンボル以外が含まれていた場合はパッチをリジェクトする仕組みを構築しました。

## 4. コアロジックの実装例

環境の変化に強いパイプラインを維持するためのコアコードの一部（`patch_pipeline.py`）です。

```python
import os
import subprocess
import requests
from typing import Dict, Any, Optional
from github import Github

OLLAMA_HOST = os.getenv("OLLAMA_HOST", "http://localhost:11434")
OLLAMA_MODEL = os.getenv("OLLAMA_MODEL", "qwen2.5-coder:7b-instruct-q4_K_M")

class PatchPipelineEngine:
    def __init__(self):
        self.ollama_url = f"{OLLAMA_HOST}/api/generate"
        self.github_client = Github(os.getenv("GITHUB_TOKEN"))

    def analyze_and_generate_patch(self, error_context: Dict[str, Any]) -> Optional[str]:
        prompt = self._build_prompt(error_context)
        payload = {
            "model": OLLAMA_MODEL,
            "prompt": prompt,
            "stream": False,
            "options": {"temperature": 0.1, "num_ctx": 4096}
        }

        try:
            response = requests.post(self.ollama_url, json=payload, timeout=60)
            response.raise_for_status()
            raw_output = response.json().get("response", "")
            
            clean_diff = self._extract_diff(raw_output)
            
            if self._validate_diff_syntax(clean_diff, error_context["file_path"]):
                return clean_diff
            return None

        except requests.exceptions.RequestException as e:
            print(f"[ERROR] Ollama Backend Unreachable: {e}")
            return None

    def _extract_diff(self, llm_output: str) -> str:
        if "```diff" in llm_output:
            return llm_output.split("```diff")[1].split("```")[0].strip()
        return llm_output.strip()

    def run_sandbox_tests(self, patch_diff: str, workspace_dir: str) -> bool:
        patch_file = os.path.join(workspace_dir, "temp_fix.patch")
        with open(patch_file, "w") as f:
            f.write(patch_diff)

        try:
            chk = subprocess.run(["git", "apply", "--check", patch_file], cwd=workspace_dir, capture_output=True)
            if chk.returncode != 0: return False

            subprocess.run(["git", "apply", patch_file], cwd=workspace_dir, check=True)
            
            test_res = subprocess.run(["pytest", "tests/"], cwd=workspace_dir, capture_output=True)
            return test_res.returncode == 0
            
        except Exception as e:
            return False
        finally:
            subprocess.run(["git", "checkout", "."], cwd=workspace_dir, capture_output=True)
```
