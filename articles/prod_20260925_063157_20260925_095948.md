TOAI結社が推進するプロジェクトの中で、絶え間なく生み出されるデータを守り抜く強靭なインフラとして構築された『LocalBackup-Guardian』のバックエンドアーキテクチャと実装のベストプラクティスを公開します。

現場のエンジニアが直面する生々しい課題、例えばI/OスパイクによるDBのハングアップやディスクフルに伴うカーネルパニック、そして「いざという時にリストアできない」という絶望に対して、OSのスケジューラやシステムコールレベルでいかにして対抗するかという実践的な記録です。

## 1. 現場導入における3大鉄則（ベストプラクティス）

### ① ionice と nice によるI/Oスパイクの抑制（共存型バックアップ）
大容量データの圧縮はLinuxのページキャッシュを急激に消費し、同一ホスト上で稼働するデータベースの書き込みをブロックします。結果としてI/O Wait率が99%に達し、コンテナが強制断殺される原因となります。

バックアッププロセスの起動時には、カーネルのI/OスケジューラおよびCPUスケジューラに対して明示的に優先度を下げるシステムコールを発行します。

```python
cmd = [
    "ionice", "-c", "3",       # Idleクラス（他のI/O要求がない時のみ動作）
    "nice", "-n", "19",         # 最低のCPU優先度
    "tar", "--exclude=*.log", "-czf", str(tmp_path),
    "-C", str(target_dir.parent), target_dir.name
]
```

### ② デッドロックを防ぐ「削除先行」の世代管理とアトミックリネーム
「新しいバックアップを作ってから古いものを消す」というフローは、ストレージ残量が逼迫した環境で致命的な障害（Disk Fullデッドロック）を引き起こします。

1. **容量の事前検証**: `os.statvfs` を用いて、新規作成の前に空き容量と安全バッファをチェックする。
2. **削除先行**: 新規作成の直前に古い世代を削除し、物理的なセクタ領域を解放する。
3. **アトミックリネーム**: 一時ファイルへの書き込み完了後、POSIXの `rename(2)` システムコールをラップした `os.replace()` を用いて本番ファイル名へ切り替える。

### ③ tmpfs（/dev/shm）を活用した安全なリストアサンドボックス
自動リストアテストの展開先として通常の物理ストレージを使用すると、NANDフラッシュの寿命を無駄に消耗します。ホストのメモリ上にマウントされた `tmpfs` をサンドボックスのベースとして優先利用することで、ディスクI/Oを発生させずに超高速な整合性検証が可能となります。

## 2. 堅牢なバックアップ・検証デーモン実装リファレンス

プロダクション環境投入可能な中核ロジックの要所となるPythonコードを以下に示します。WALモードによるSQLiteの強制終了耐性向上など、シニアエンジニアの知見が詰め込まれています。

```python
#!/usr/bin/env python3
import os
import sys
import subprocess
import logging
import sqlite3
import hashlib
from pathlib import Path
from datetime import datetime

logging.basicConfig(
    level=logging.INFO,
    format="%(asctime)s [%(levelname)s] %(name)s: %(message)s",
    handlers=[logging.StreamHandler(sys.stdout)]
)
logger = logging.getLogger("BackupGuardianBestPractice")

class ProductionReadyBackupGuardian:
    def __init__(self, target_dir: str, backup_dest: str, max_generations: int = 5, min_free_space_gb: float = 5.0):
        self.target_dir = Path(target_dir).resolve()
        self.backup_dest = Path(backup_dest).resolve()
        self.max_generations = max_generations
        self.min_free_space_bytes = int(min_free_space_gb * 1024 * 1024 * 1024)
        self.db_path = self.backup_dest / "guardian_meta.db"
        
        self.backup_dest.mkdir(parents=True, exist_ok=True, mode=0o700)
        self._init_db()

    def _init_db(self):
        with sqlite3.connect(self.db_path) as conn:
            conn.execute("PRAGMA journal_mode=WAL;")
            conn.execute("PRAGMA synchronous=NORMAL;")
            conn.execute("""
                CREATE TABLE IF NOT EXISTS backup_logs (
                    id INTEGER PRIMARY KEY AUTOINCREMENT,
                    filename TEXT NOT NULL,
                    sha256 TEXT NOT NULL,
                    size_bytes INTEGER NOT NULL,
                    restore_test_passed INTEGER NOT NULL,
                    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
                )
            """)
            conn.commit()
        if self.db_path.exists():
            os.chmod(self.db_path, 0o600)

    def _check_disk_space(self, required_bytes: int) -> bool:
        stat = os.statvfs(self.backup_dest)
        free_bytes = stat.f_bavail * stat.f_frsize
        if free_bytes < (required_bytes + self.min_free_space_bytes):
            logger.error("CRITICAL: Insufficient disk space including safety buffer. Aborting backup.")
            return False
        return True

    def prune_old_generations(self):
        with sqlite3.connect(self.db_path) as conn:
            cursor = conn.cursor()
            cursor.execute("SELECT id, filename FROM backup_logs ORDER BY created_at DESC")
            rows = cursor.fetchall()

            if len(rows) >= self.max_generations:
                excess_rows = rows[self.max_generations - 1:]
                for row_id, filename in excess_rows:
                    safe_filename = Path(filename).name
                    target_file = self.backup_dest / safe_filename
                    if target_file.exists() and target_file.is_file():
                        target_file.unlink()
                        logger.info(f"Pruned old backup generation: {safe_filename}")
                    cursor.execute("DELETE FROM backup_logs WHERE id = ?", (row_id,))
                conn.commit()

    def create_backup(self) -> Path:
        timestamp = datetime.now().strftime("%Y%m%d_%H%M%S")
        tmp_path = self.backup_dest / f"backup_{timestamp}.tar.gz.tmp"
        final_path = self.backup_dest / f"backup_{timestamp}.tar.gz"

        estimated_size = sum(f.stat().st_size for f in self.target_dir.glob('**/*') if f.is_file() and not f.is_symlink())
        
        if not self._check_disk_space(estimated_size):
            raise OSError("Disk space safety threshold breached.")

        self.prune_old_generations()

        logger.info(f"Starting low-priority compression: {self.target_dir} -> {tmp_path}")
        cmd = [
            "ionice", "-c", "3", 
            "nice", "-n", "19", 
            "tar", "--no-same-owner", "--no-same-permissions", "--exclude=*.log", "-czf", str(tmp_path), 
            "-C", str(self.target_dir.parent), self.target_dir.name
        ].
        
        result = subprocess.run(cmd, capture_output=True, text=True)
        if result.returncode != 0:
            if tmp_path.exists():
                tmp_path.unlink()
            raise RuntimeError(f"Backup compression failed: {result.stderr}")

        os.chmod(tmp_path, 0o600)
        tmp_path.replace(final_path)
        logger.info(f"Atomic backup committed: {final_path.name}")
        return final_path

    def verify_and_test_restore(self, archive_path: Path) -> bool:
        sandbox_base = Path("/dev/shm") if Path("/dev/shm").exists() else self.backup_dest
        test_dir = sandbox_base / f"restore_test_sandbox_{os.getpid()}"
        test_dir.mkdir(parents=True, exist_ok=True, mode=0o700)

        logger.info(f"Running automated restore test in sandbox: {test_dir}")
        cmd = ["tar", "--no-same-owner", "--no-same-permissions", "-xzf", str(archive_path), "-C", str(test_dir)]
        result = subprocess.run(cmd, capture_output=True, text=True)
        
        passed = 1 if result.returncode == 0 else 0
        
        # クリーンアップ処理...
        file_size = archive_path.stat().st_size
        sha256_hash = hashlib.sha256()
        with open(archive_path, "rb") as f:
            for byte_block in iter(lambda: f.read(65536), b""):
                sha256_hash.update(byte_block)
        file_hash = sha256_hash.hexdigest()

        with sqlite3.connect(self.db_path) as conn:
            conn.execute(
                "INSERT INTO backup_logs (filename, sha256, size_bytes, restore_test_passed) VALUES (?, ?, ?, ?)",
                (archive_path.name, file_hash, file_size, passed)
            )
            conn.commit()

        return bool(passed)
```
