グローバル展開を前提としたSaaS開発において、i18n（国際化）とタイムゾーンはエンジニアの睡眠時間を削り取る泥沼となり得ます。本記事では、文字コードやタイムゾーンに起因する本番障害を水際で防ぎ切るための具体的なアーキテクチャと実装パターンを解説します。

## 1. 深夜2時の絶望 — サロゲートペアとDSTの罠

「すべての文字列をUTF-8にすれば動く」「すべてのタイムスタンプをUTCで保存すれば安全だ」という原則を信じきっていても、現実のデータは牙を剥きます。

```text
[202X-10-31 02:15:43.112 UTC] ERROR: 22P05: invalid byte sequence for encoding "UTF8": 0xed 0xa0 0x80
[202X-10-31 02:15:43.113 UTC] CONTEXT: COPY users, line 4212, column bio: "Developer \ud800..."
[202X-10-31 02:15:43.120 UTC] FATAL: current transaction is aborted, commands ignored until end of transaction block
```text
PostgreSQLなどのデータベースは文字コードに厳格であり、不正なバイト列（サロゲートペアの片割れ単体の混入など）を検知した瞬間にトランザクションをアボートします。クライアント側でのサニタイズを怠った結果、バッチ全体が停止する事態に陥ります。

さらに、タイムゾーンや夏時間（DST）の切り替わり時には、ローカルタイム文字列による範囲検索が原因で「バッチの二重計上」や「データロスト」を引き起こします。

## 2. 絶望を断ち切る「3つの鉄壁の防衛ライン」

明日発生する本番障害を防ぐため、TOAIのシステム群で導入しているフェイルセーフの実装を紹介します。

### 🛡️ 防衛ライン 1：文字列・エンコーディングガード (`Utf8SanitizationMiddleware`)

DBへ到達する前に、APIゲートウェイのミドルウェア層で不正な文字コードを破棄します。

```python
import unicodedata
from fastapi import Request
from starlette.middleware.base import BaseHTTPMiddleware
from starlette.responses import JSONResponse

class Utf8SanitizationMiddleware(BaseHTTPMiddleware):
    async def dispatch(self, request: Request, call_next):
        content_type = request.headers.get("content-type", "")
        if "application/json" in content_type:
            try:
                body = await request.body()
                decoded_body = body.decode("utf-8", errors="strict")
                normalized_body = unicodedata.normalize("NFC", decoded_body)
                request.state.sanitized_body = normalized_body
            except UnicodeDecodeError as e:
                return JSONResponse(
                    status_code=400,
                    content={
                        "error": "INVALID_ENCODING",
                        "message": "Request body contains invalid UTF-8 byte sequence.",
                        "details": str(e)
                    }
                )
        response = await call_next(request)
        return response
```text
`errors="strict"` の指定によりサイレントなデータ欠損を防ぎ、さらに `unicodedata.normalize("NFC", ...)` によって文字コードの等価性を保証して検索漏れを防ぎます。

### 🛡️ 防衛ライン 2：タイムゾーン・DST破綻防止ガード (`StrictTimestampModel`)

Pydantic V2を活用し、型レベルで `naive datetime` の混入を拒絶します。

```python
from datetime import datetime, timezone
from pydantic import BaseModel, Field, field_validator

class StrictTimestampModel(BaseModel):
    event_id: str
    occurred_at: datetime = Field(..., description="必ずUTC、またはオフセット付きのISO8601形式であること")

    @field_validator("occurred_at", mode="before")
    @classmethod
    def validate_and_normalize_timezone(cls, v):
        if isinstance(v, str):
            try:
                parsed_dt = datetime.fromisoformat(v.replace("Z", "+00:00"))
            except ValueError as e:
                raise ValueError(f"Invalid ISO8601 datetime format: {v}") from e
        elif isinstance(v, datetime):
            parsed_dt = v
        else:
            raise TypeError("Unsupported datetime type")

        if parsed_dt.tzinfo is None:
            raise ValueError(
                "Naive datetime is strictly prohibited. "
                "Always provide timezone-aware datetimes (e.g., UTC with 'Z' or '+00:00')."
            )

        return parsed_dt.astimezone(timezone.utc)
```text
スキーマ層で `tz-aware` を強制し即座にUTCへ変換することで、ビジネスロジック層の複雑性を劇的に削減できます。

### 🛡️ 防衛ライン 3：多言語・複数通貨バリデーションチェッカー（CI/CD）

プルリクエストの段階で危険なコードを検出する軽量なCLIスキャナーを導入します。

```python
#!/usr/bin/env python3
import os, re, sys

ANTIPATTERNS = [
    {
        "id": "TZ_001",
        "severity": "CRITICAL",
        "pattern": re.compile(r"datetime\.now\(\)", re.IGNORECASE),
        "message": "datetime.now() is used without timezone. Use datetime.now(timezone.utc) instead."
    },
    {
        "id": "CUR_001",
        "severity": "HIGH",
        "pattern": re.compile(r"float\s*\(\s*['\"].*price|amount|fee", re.IGNORECASE),
        "message": "Using float for currency calculation causes rounding errors. Use Decimal."
    }
]

def scan_directory(target_dir: str) -> int:
    error_count = 0
    for root, _, files in os.walk(target_dir):
        for file in files:
            if file.endswith((".py", ".ts", ".js")):
                filepath = os.path.join(root, file)
                with open(filepath, "r", encoding="utf-8") as f:
                    content = f.read()
                    for line_no, line in enumerate(content.splitlines(), 1):
                        for ap in ANTIPATTERNS:
                            if ap["pattern"].search(line):
                                print(f"[{ap['severity']}] {ap['id']} in {filepath}:{line_no}")
                                error_count += 1
    return error_count
