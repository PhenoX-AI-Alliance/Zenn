# はじめに

近年のAIコーディング支援の進化は目覚ましいものがあります。特に Anthropic の **Claude Code** を活用することで、開発者はコンソール上から自然言語で高度なリファクタリングや機能追加を自律的に行えるようになりました。

本記事では、筆者が実践している「**Claude Codeを2時間おきにcron等のジョブで自動実行し、VS Code拡張機能のMarkdownエディタを継続的に育成-進化させる Loop Engineering（ループ-エンジニアリング）**」の手法について、その技術的仕組みと、持続可能な開発プロセスがもたらす地球環境レジリエンス（持続的発展）への寄与について解説します。

---

# 1. Loop Engineeringとは何か？

人間が常にコードを書き続けるのではなく、AIエージェントに「小さな単位のタスク（Issueや改善要望）」を与え、定期的なループ（2時間おきなど）の中でコード生成、自動テスト、ビルド、コミットまでを自律的に回させる手法です。

## 実装の概要
1. **タスクキューの定義**: 次に実装すべき機能や修正点を `TODO.md` やイシュー管理用JSONに記載。
2. **自動実行スクリプト**: 2時間おきにCronで起動し、現在のコードベースの状態をClaude Codeにプロンプトとして渡す。
3. **自己修復と拡張**: Claude CodeがVS Code拡張機能（TypeScript製）に新機能（例：リアルタイムプレビューの高速化、数式レンダリングの強化など）を追加。
4. **テストと検証**: 自動テスト（`npm test`）を通過した場合のみ、Gitリポジトリへ自動コミット。

---

# 2. VS Code拡張mdエディタ育成の実際

今回育てているのは、日々の執筆活動を爆速化するための特製Markdownエディタ拡張機能です。Claude Codeに以下のようなプロンプトを2時間ごとに与えることで、驚異的なスピードで機能が拡張されています。

- 「VS Code拡張のMarkdownプレビューにおいて、Mermaid図のレンダリングエラー耐性を高めてください」
- 「エディタ内に文字数および読了時間カウンターをリアルタイム表示するStatusBarItemを追加してください」
- 「コードブロックのワンクリックコピーボタンをプレビュー画面に実装してください」

人間は全体の方向性（アーキテクチャの指針）を示すだけで、細部の実装やボイラープレートコードの記述はすべてClaude Codeが自律的に完了させます。

---

# 3. 地球環境の持続的発展（レジリエンス）への寄与

「AIにコードを書かせること」と「地球環境」にどのような関係があるのか、疑問に思われるかもしれません。しかし、Loop Engineeringの本質は**「無駄なリソース消費の抑制と、知的生産性の最大化によるレジリエンスの向上」**にあります。

1. **開発プロセスの最適化によるエネルギー効率の向上**
   - 人間が何時間も悩み、何度もコンテキストスイッチを繰り返しながらコードを書くプロセスは、脳のエネルギーだけでなく、オフィス環境全体の電力消費を伴います。
   - 高効率なAIエージェントがピンポイントで最適解を生成することで、開発にかかる時間と総エネルギーコストを劇的に圧縮できます。
2. **レジリエント（回復力-持続可能性）なソフトウェアの自動生成**
   - 2時間おきのループによって常にコードのテストとリファクタリングが行われるため、技術的負債が蓄積しにくくなります。
   - 長寿命で保守性の高いソフトウェアは、頻繁なリプレイスやそれに伴うハードウェア-エネルギーの無駄遣いを防ぎます。
